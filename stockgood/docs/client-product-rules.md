# 客户端产品规范（模式 B）

本文档把客户侧「已经拍板」的规则写成死规定，避免个人页/申请流来回改。实现以代码为准；若代码与本文冲突，先改代码或先改本文并升版本说明。

一句话总规：

> 客户：在 `/apply` 登录后下单，先付 30% 定金再正式提交；在用户名菜单进出个人主页与退出；`/me` 看自己的单、确认定金（可附支付单号与截图）并可改昵称/密码，不做退出。注册用邮箱密码即可，不必三方。订单号对客户只显示账户流水；未登录不可查看订单。

**实现状态（2026-08-12）**：下列「已拍板」规范以本文为准。**个人主页相关能力先记录、暂不开发**（见第 8 节待办）；现有 `/me` / 定金确认代码仍为旧行为，待专门开「个人主页」迭代时再对齐。

---

## 1. 角色与入口

| 角色 | 入口 | 说明 |
|---|---|---|
| 客户 | `/apply`、`/me` | 下单台 + 我的单 / 登录注册 / 轻量账号设置 |
| 员工 | `/` | 库存后台（订单/进库/出库/财务/统计/申请单等） |

- **不做**（多年内）：多租户 SaaS；网站自动下单付款（定金支付网关以后再接；对接前用手动确认 + 凭证）。

---

## 2. 登录与账号入口

- **未登录禁止提交申请**。
- **未登录不可查看订单**（含申请页全站列表与 `/me` 我的单；须登录后只看自己的）。
- 注册 = **本地邮箱 + 密码**，**不接三方**（微信 / Google / 短信等为可选后续）。
- `/apply` 右上角：
  - 未登录 →「登录查看我的申请」→ `/me`
  - 已登录 → **用户名菜单：个人主页 / 退出**
- **退出只在 `/apply` 用户名菜单**；`/me` **不做退出按钮**。

### 已拍板的细节（第二节定稿）

1. **`/me` 未登录页**：登录与注册 **同页切换**（不拆两个独立入口）。
2. **个人页标题信息**：显示 **昵称 + 邮箱**。
3. **改密码 / 改昵称**：**要进 `/me`**（轻量账号设置；完整「设置中心」仍不做）。
4. **订单可见性**：**未登录无法查看订单**（不再提供未登录脱敏公开列表）。
5. **定金「确认已付」**（财务系统对接前）：
   - 客户可自助提交「已付」申请，并须填写 **支付订单号** + 上传 **支付截图**；
   - 后台支付状态须 **员工二次确认** 后，申请才进入「已提交」；
   - 后续上线接入财务系统后，以支付回调为主，再评估是否保留客户自助凭证流程。
6. **支付对接前文案**：界面 **固定写**「财务系统对接前可手动确认」，避免客户误解已真实扣款。

## 3. 下单与定金

```text
选货并填单价
  → 创建「待付定金」
  → 客户提交：支付订单号 + 截图（自助「确认已付」）
  → 员工二次确认支付状态
  → 「已提交」
  → 员工处理下单
```

- 定金默认：**商品金额 × 30%**（环境变量 `STOCKGOOD_DEPOSIT_RATE`）。
- **无单价不可创建**申请。
- 员工不可对「待付定金」或「待员工确认支付」的申请直接「确认已下单」。
- 文案须含：**「财务系统对接前可手动确认」**。

## 4. 订单号

| 字段 | 格式 | 谁看见 |
|---|---|---|
| `account_order_no` 账户流水 | `SG{用户ID}-0001…` | **仅用户端**展示 |
| `request_code` 全站流水 | `SG-0001…` | **后台**展示（与账户流水一起）；统计/台账 |

---

## 5. `/me` 职责（我的订单中心 + 轻量账号）

**做（规范已定；实现见第 8 节）：**

- 登录 / 注册（同页切换）
- 标题区：昵称 + 邮箱
- 改昵称 / 改密码
- 查看自己的申请（状态筛选）；未登录不展示任何订单列表
- 对待付定金：提交支付订单号 + 截图；等待员工确认
- 链回「申请下单」`/apply`

**不做：**

- 退出按钮（退出仅在 `/apply` 用户名菜单）
- 收货地址簿、三方绑定、完整「设置」页

---

## 6. 员工侧（与客户相关）

- 对客户提交的定金凭证做 **二次确认**（通过后申请才「已提交」）；也可代处理异常。
- 未付定金 / 支付未二次确认前，不能确认下单进库存。
- 「统计」：日/月单量、热门链接、花费用户、商品 IP。
- 申请单列表同时显示账户流水与全站流水。

## 7. 明确推迟

- 微信 / Apple / Google / 短信验证码登录
- 真实支付网关（支付宝 / 微信等）与支付回调替代手动确认 + 凭证
- 收货地址簿、完整账号设置中心
- 多租户 SaaS、自动爬站下单

# 更新日志

格式依据 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

项目主版本见根目录 `VERSION`，并与 `backend/app/main.py`、`frontend/package.json` 保持一致。

## [0.9.2] - 2026-08-12

### 文档

- README 补充「可服务器化 · 模式 B」定位：已落地（部署/账号/定金申请/双编号/统计）、明确未做、影子库本地测试；并修正账号说明（申请须登录）

## [0.9.1] - 2026-08-12

### 变更

- 双编号：全站流水 `request_code`（SG-0001…）+ 账户流水 `account_order_no`（SGuid-0001…）；用户端只显示账户流水，员工后台两者都显示

## [0.9.0] - 2026-08-12

### 新增

- 后台「统计」页：按日/月查看申请单量、状态分布、热门链接、花费最多用户、商品 IP

### 变更

- 申请订单号改为全站流水 `SG-0001` 起（按创建先后），便于台账与月报；旧按账户编号保留不改写

## [0.8.0] - 2026-08-12

### 新增

- 申请须登录；新建为「待付定金」（商品金额 30%），确认付款后才变为「已提交」
- 客户/员工均可确认定金；预留 `payment_ref` 与 `STOCKGOOD_DEPOSIT_RATE`，便于后续对接财务支付回调

### 变更

- 未登录提交返回 401；员工不可对未付定金申请执行「确认已下单」

## [0.7.2] - 2026-08-12

### 变更

- 申请订单号按账户提交先后递增生成：`SG{用户ID}-0001` 起；未登录走 `SG0-0001` 起；列表「订单号」显示该编号（店铺注文番号改悬停提示）

## [0.7.1] - 2026-08-12

### 变更

- 申请页：账号入口移至右上角；未登录显示「登录查看我的申请」，已登录显示昵称与「下单历史」

## [0.7.0] - 2026-08-12

### 新增

- 账号系统（模式 B）：会话 Cookie 登录；角色 admin / warehouse / finance / customer；客户自助注册与「我的申请」`/me`
- 员工 API（含只读列表）按角色鉴权；操作日志记录 `actor_user_id`；申请单可绑定 `user_id`
- 可选 SMTP 邮件：申请提交 / 确认下单 / 拒绝时通知
- 服务器部署：`Dockerfile`、`docker-compose.yml`、Nginx 配置、Linux 备份脚本、[`docs/deploy.md`](docs/deploy.md)
- `/api/health` 增加磁盘与最近备份信息；生产可托管前端静态资源

### 变更

- 兼容保留 `STOCKGOOD_ADMIN_TOKEN`；生产推荐 bootstrap 管理员 + `STOCKGOOD_AUTH_REQUIRED=true`
- CORS 可通过 `STOCKGOOD_CORS_ORIGINS` 收紧

## [0.6.2] - 2026-08-12

### 新增

## [0.6.1] - 2026-08-12

### 变更

## [0.6.0] - 2026-08-12

### 新增

- Windows 系统托盘：`start-tray.bat` 后台托管前后端，托盘可打开界面 / API 文档 / 停止退出（开机不弹浏览器）
- 开机自启：`install-autostart.bat` / `uninstall-autostart.bat`（当前用户 Startup 快捷方式）

## [0.5.3] - 2026-08-08

### 新增

- 库存合箱：可选「目标箱」后点「合箱」——未选则新建，已选则合入（按钮文案变为「将订单添加到 #N」）；成功后目标箱与箱子备注自动清空；箱号筛选不因合箱操作自动切换
- 重要约束：未明确要求改 UI 位置/布局时，只改逻辑，不擅自改界面

## [0.5.2] - 2026-08-08

### 变更

- 商品种类：`ぬいぐるみ` / `ぬい` / `マスコット` / plush 归为「玩偶」（不再标成「挂件」）；启动时纠正此前误标为挂件的玩偶明细

## [0.5.1] - 2026-08-08

### 新增

- 商品种类：下拉选择可手动更改标签（库存明细 / 订单明细）
- 种类识别：扩充日语关键字（缶バッジ / アクスタ / トレカ 等），支持半角片假名 NFKC 归一；新增「贴纸」种类

### 变更

- `/api/product-kinds` 返回 `{ labels, aliases }`，便于前端下拉

## [0.5.0] - 2026-08-08

### 新增

- 库存商品明细：按品名关键字自动识别商品种类（吧唧 / 立牌 / 海报 / 小卡等），并在明细中标注；关键字可在 `backend/data/product_kinds.json` 调整

## [0.4.1] - 2026-08-08

### 变更

- 库存箱号筛选：子箱缩进挂在对应主箱下方，不再与主箱平级罗列

## [0.4.0] - 2026-08-08

### 新增

- 财务：订单下单汇率、出库批次货款应收 / 国际运费独立汇率、已收未收、财务月汇总、发货费用明细 Excel（含订单号列）

- 库存合箱：可将当前箱（B）作为子箱并入所选主箱（A）；支持从主箱拆出

### 变更

- 重要约束：每次可交付改动须写更新日志并提升版本号

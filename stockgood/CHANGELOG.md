# 更新日志

格式依据 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

项目主版本见根目录 `VERSION`，并与 `backend/app/main.py`、`frontend/package.json` 保持一致。

## [0.5.1] - 2026-08-08

### 新增

- 商品种类：下拉选择可手动更改标签（库存明细 / 订单明细）
- 种类识别：扩充日语关键字（缶バッジ / アクスタ / トレカ 等），支持半角片假名 NFKC 归一；新增「贴纸」种类

### 变更

- `/api/product-kinds` 返回 `{ labels, aliases }`，便于前端下拉

## [0.5.0] - 2026-08-08

### 新增

- 库存商品明细：按品名关键字自动识别商品种类（吧唧 / 立牌 / 海报 / 小卡等），并在明细中标注；关键字可在 `backend/data/product_kinds.json` 调整

## [0.4.1] - 2026-08-08

### 变更

- 库存箱号筛选：子箱缩进挂在对应主箱下方，不再与主箱平级罗列

## [0.4.0] - 2026-08-08

### 新增

- 财务：订单下单汇率、出库批次货款应收 / 国际运费独立汇率、已收未收、财务月汇总、发货费用明细 Excel（含订单号列）
- 库存：按店铺 / IP 等搜索、列表全选、合箱时一并保存备注
- 库存合箱：可将当前箱（B）作为子箱并入所选主箱（A）；支持从主箱拆出

### 变更

- 重要约束：每次可交付改动须写更新日志并提升版本号

## [0.3.0] - 2026-08

### 新增

- 订单 + 明细、进库 / 出库、顾客申请、抓取导入、库存合箱、操作撤回等基础能力

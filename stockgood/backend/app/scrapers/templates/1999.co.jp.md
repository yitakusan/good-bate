# 1999.co.jp（HobbySearch / ホビーサーチ）商品页模板

样例：`https://www.1999.co.jp/11350341`  
实现：`app/scrapers/hobbysearch.py`  
DOM 摘录：`templates/1999.co.jp.snippet.html`

## URL

| 形态 | 示例 |
|------|------|
| 日文商品页 | `https://www.1999.co.jp/{productId}` |
| 英文商品页 | `https://www.1999.co.jp/eng/{productId}` |

`productId` 为 6 位以上数字（例：`11350341`）。

## 抓取注意

- 对普通 `httpx`/`requests` 常返回 Cloudflare challenge（403 / Just a moment）。
- 本站抓取走系统 `curl`（Windows: `curl.exe`），UA 模拟桌面 Chrome。
- 价格取 **販売価格**，不要取「メーカー希望小売価格」或推荐栏卡片价。

## DOM / 字段映射（日文页，2026-08 核对）

| 字段 | 选择器 / 来源 | 样例值 |
|------|----------------|--------|
| 商品名 | `h1`（非空且非站点名）；fallback `og:title` | `『デート・ア・ライブ』トレーディングホログラム缶バッジ～狂三がいっぱい～ (9個セット) (キャラクターグッズ)` |
| 販売価格 | `.c-product-detail__info-price-element` | `¥ 4,207` |
| 定价（勿作进货价） | `#masterBody_stickerPrice` / `.c-product-detail__info-price-del` | `メーカー希望小売価格：¥4,950 (税込)` |
| 折扣标签 | `#masterBody_priceReductionRate` | `15 %OFF` |
| 発売日 | `#masterBody_salesDate` | `発売日：2026年6月中旬` |
| 主图 | `meta[property=og:image]`；fallback `#masterBody_ulThumnail img[src*=itbig]` | `https://www.1999.co.jp/itbig135/11350341.jpg` |
| 系列 / IP | `dl.c-spec dt` 含「シリーズタイトル」的下一 `dd` | `デート・ア・ライブ` |
| 商品コード | 同上 dt「商品コード」 | `146684` |
| JAN | 同上 dt「JANコード」 | `4550687146684` |

## 关键结构片段

```html
<div class="c-product-detail__info-price">
  <div class="c-product-detail__info-price-tags">15 %OFF</div>
  <div class="c-product-detail__info-price-body">
    <span class="c-product-detail__info-price-label">販売価格</span>
    <span class="c-product-detail__info-price-element">¥ 4,207</span>
    <span class="c-product-detail__info-price-del">メーカー希望小売価格：¥4,950 (税込)</span>
  </div>
</div>
<div id="masterBody_salesDate">発売日：2026年6月中旬</div>
<dl class="c-spec c-spec-itempage">
  <dt>シリーズタイトル</dt><dd>デート・ア・ライブ</dd>
  <dt>商品コード</dt><dd>146684</dd>
  <dt>JANコード</dt><dd>4550687146684</dd>
</dl>
```

## ASP.NET 控件 id（辅助）

页面大量使用 `masterBody_*`：

- `#masterBody_pnlItemDetails` — 商品详情主区
- `#masterBody_stickerPrice` — 希望小売価格
- `#masterBody_salesDate` — 発売日
- `#masterBody_ulThumnail` — 缩略图列表

推荐商品卡片（`.c-card__price-element`）价格会混入页面，解析时必须限定在 `.c-product-detail__info-price*` 内。
